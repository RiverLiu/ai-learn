# 01 工具权限

工具调用的安全边界在应用侧，不在模型侧。模型只能提出调用意图，真正执行前必须由系统校验权限、参数和风险。

## 风险分级

| 等级 | 示例 | 策略 |
| --- | --- | --- |
| 低 | 搜索知识库、读取公开配置 | 可直接执行 |
| 中 | 查询客户记录、读取内部文档 | 需要权限过滤和审计 |
| 高 | 发邮件、改数据库、退款、删除文件 | 需要人工确认 |

## 示例

```json
{
  "tool": "send_email",
  "risk": "high",
  "requires_approval": true,
  "allowed_roles": ["support_manager"]
}
```

## 练习

为一个客服 Agent 设计 5 个工具，并标注风险等级、允许角色和是否需要人工确认。
