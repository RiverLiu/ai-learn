# Python 基础教程：json、asyncio、aiohttp

三个主题按"数据 → 并发 → 网络"的顺序排，层层递进：

1. **json**：程序之间交换数据的通用语言。无论是存配置文件还是调 HTTP API，
   你收到的几乎都是 JSON。这是后面一切的基础。
2. **asyncio**：Python 的异步并发模型。当程序大量时间花在"等待"（网络、磁盘）上时，
   异步能让一个线程同时推进成百上千个任务。这是理解现代 Python 网络编程的关键。
3. **aiohttp**：建立在 asyncio 之上的 HTTP 客户端 + 服务器库。
   学会它，就能写出"同时请求一百个 API 也不慢"的程序。

三章都可以离线运行（第 3 章的服务器也由脚本自己启动），直接看输出理解概念。

## 常见面试题

**Q1：JSON 中的 `null`、`true`、`false` 在 Python 中分别对应什么？**

参考答案：`null` 对应 `None`，`true` 对应 `True`，`false` 对应 `False`。JSON 是跨语言数据格式，不等同于 Python 字面量。

**Q2：`json.dumps` 和 `json.loads` 有什么区别？**

参考答案：`dumps` 把 Python 对象序列化为 JSON 字符串，`loads` 把 JSON 字符串反序列化为 Python 对象。`dump` 和 `load` 则面向文件对象。

**Q3：为什么 JSON 字符串必须使用双引号？**

参考答案：JSON 标准规定对象键和字符串值使用双引号，单引号是 Python 字面量风格，不是合法 JSON。接口请求体必须遵守 JSON 标准。

**Q4：`asyncio` 适合解决什么问题？**

参考答案：`asyncio` 适合 I/O 密集型任务，例如并发请求模型 API、数据库、向量库或第三方 HTTP 服务。它不是让 CPU 计算变快，而是在等待 I/O 时切换任务。

**Q5：协程和线程有什么区别？**

参考答案：协程由事件循环在单线程内调度，切换成本低，适合大量 I/O；线程由操作系统调度，适合阻塞库或部分并发场景，但开销更高。

**Q6：为什么异步函数里要避免阻塞调用？**

参考答案：阻塞调用会卡住事件循环，让其它协程无法运行。异步代码中应使用异步 HTTP 客户端、异步数据库驱动，或把阻塞任务放到线程池。

**Q7：`aiohttp` 和 `requests` 的主要区别是什么？**

参考答案：`requests` 是同步 HTTP 客户端，适合少量请求；`aiohttp` 支持异步请求，适合高并发 I/O 场景，如并发调用多个外部工具。

**Q8：AI 应用中为什么常见 JSON？**

参考答案：LLM API 请求和响应、工具调用参数、结构化输出、配置和评估数据都常用 JSON。掌握 JSON 读写和校验是后续学习的基础。

**Q9：`ensure_ascii=False` 有什么作用？**

参考答案：它让中文等非 ASCII 字符按原文输出，而不是转义成 `\u` 序列。对日志、示例数据和人工阅读更友好。

**Q10：异步并发为什么要设置超时？**

参考答案：外部 API 或网络请求可能长时间无响应。超时能避免任务无限等待，释放资源，并让应用进入重试、降级或错误提示流程。
