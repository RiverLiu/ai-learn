# Python 开发工具

本目录介绍 Python 开发中常用的环境管理工具。

## 目录

- `01_python_venv.md`：Python 内置虚拟环境 `venv` 基础
- `02_uv.md`：现代 Python 包管理器 `uv` 基础
- `03_uv_demo/`：一个最小的 uv 项目示例
- `04_uvicorn.md`：ASGI Web 服务器 Uvicorn 介绍
- `04_uvicorn_demo/`：纯 ASGI 应用示例

## 学习目标

1. 理解为什么需要虚拟环境
2. 掌握 `venv` 的基本用法
3. 掌握 `uv` 的常用命令
4. 能够使用 `uv` 管理项目依赖和运行脚本
5. 理解 Uvicorn 的作用和基本用法
