# uv 包管理器基础

## 什么是 uv

[uv](https://docs.astral.sh/uv/) 是由 Astral 公司开发的 Python 包管理器，使用 Rust 编写，目标是替代 `pip`、`pip-tools`、`virtualenv` 等工具。

**主要特点**：

- 极速：依赖解析和安装速度远超 pip
- 兼容 pip：支持 `requirements.txt` 和大多数 pip 命令
- 内置虚拟环境管理：自动创建和维护 `.venv`
- 基于 `pyproject.toml`：现代 Python 项目标准配置
- 生成 `uv.lock`：精确的依赖锁定文件

## 安装 uv

### macOS / Linux

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Windows

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 验证安装

```bash
uv --version
```

## 常用命令

### 初始化项目

```bash
uv init my-project
cd my-project
```

会生成 `pyproject.toml` 和 `main.py`。

### 添加依赖

```bash
uv add requests
uv add "fastapi>=0.115.0"
```

### 删除依赖

```bash
uv remove requests
```

### 安装所有依赖

```bash
uv sync
```

### 运行脚本

```bash
uv run python main.py
```

`uv run` 会自动激活正确的虚拟环境。

### 运行命令（不通过 Python）

```bash
uv run pytest
uv run black .
```

### 创建虚拟环境

```bash
uv venv
```

默认创建 `.venv`，也可以指定名称：

```bash
uv venv myenv
```

### 使用 pip 子命令

```bash
uv pip install requests
uv pip list
uv pip freeze
```

### 升级依赖

```bash
uv lock --upgrade
uv sync
```

## pyproject.toml 基础

`pyproject.toml` 是 Python 项目的标准配置文件，uv 通过它管理依赖。

```toml
[project]
name = "my-project"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.12"
dependencies = [
    "requests>=2.32.0",
]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"
```

关键字段：

- `name`：项目名称
- `version`：项目版本
- `requires-python`：最低 Python 版本
- `dependencies`：直接依赖列表

## uv.lock

`uv.lock` 是由 `uv sync` 或 `uv lock` 生成的锁定文件，记录了每个依赖的精确版本和哈希值。

**应该提交到 Git**：是的，`uv.lock` 和 `Cargo.lock`、`package-lock.json` 类似，应该加入版本控制，确保团队环境一致。

**不要手动编辑**：由 uv 自动生成和更新。

## 完整工作流示例

```bash
# 1. 创建项目
uv init my-project
cd my-project

# 2. 添加依赖
uv add requests

# 3. 编写代码
# 编辑 main.py

# 4. 运行
uv run python main.py

# 5. 安装所有依赖（已有项目）
uv sync
```

## venv 与 uv 的关系

uv 底层仍然使用虚拟环境（默认 `.venv`），但隐藏了手动激活的步骤：

- `uv sync` 会自动创建/更新 `.venv`
- `uv run` 会自动使用 `.venv` 中的 Python
- 不需要手动 `source .venv/bin/activate`

## 常见问题

### 1. uv 和 pip 能一起用吗？

可以，但不推荐。如果混合使用，下次 `uv sync` 可能会覆盖 pip 安装的包。

### 2. 已有 requirements.txt 怎么办？

```bash
uv pip install -r requirements.txt
# 或者转换为 pyproject.toml
uv add $(cat requirements.txt)
```

### 3. 如何指定 Python 版本？

```bash
uv python install 3.12
uv python pin 3.12
```

### 4. uv 支持 Conda 吗？

uv 主要面向 PyPI 生态，不支持 Conda。Conda 用户可以继续使用 Conda。
