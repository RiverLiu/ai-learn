# 04 思维链：先推理，后答案，再自我检查

模型直接报答案时，你无法知道它是真算出来的还是蒙对的。思维链（Chain-of-Thought, CoT）
的做法简单到不像技巧：**让它"先列出推理过程，再给出最终答案"**——
写过程迫使模型一步一步算，也让你能逐步检查它错在哪。再加一句
"把答案代回题目自我检查一遍"，就是第二道保险。

## 本章要点

- **三道陷阱题**（小学难度）：锯木料（单位换算 + "段数比锯的次数多 1"）、
  鸡蛋倒推（还原问题）、分苹果（盈亏问题）。
- **三种提示词现场对比**：
  1. 坏："直接给出最终答案，不要写任何计算过程"；
  2. 好："先列出推理过程（注意单位换算和隐藏条件），再给出最终答案"；
  3. 更好：在上一条基础上加"把答案代回题目重新验算一遍"。
- **诚实的实验结果**（本章最重要的认识）：本章默认的思考型模型（kimi-k2.6）
  把推理放在内部完成，三种提示词**全部答对**，得分表打平——
  **模型越强，提示词差异越小，但方法通用**。差异在非思考型模型上是决定性的，
  实测 `moonshot-v1-8k` 同一套题：

  | 提示词 | 第 1 题（450 秒） | 第 2 题（120 个） | 第 3 题（9 名，57 个） |
  | --- | --- | --- | --- |
  | 直接答 | 1020 ✗ | 124 ✗ | 18、102 ✗ |
  | 先推理后答案 | 450 ✓ | 120 ✓ | 9 名，57 个 ✓ |

- **直接答的隐性代价**：即使答对，答案也无法审计——它说 450，
  你不知道它有没有踩中"段数-1"的陷阱；写出过程则每一步可查。


## 核心概念

- **思维链（CoT）**：在提示词里要求模型先写推理过程再给答案。对多步推理题
  （数学、单位换算、逻辑），它能显著降低错误率——原理是模型生成过程时
  等于给自己打了草稿。
- **思考型模型 vs 非思考型模型**：思考型模型（如 kimi-k2.6、o 系列）在模型内部
  自动完成推理（输出里的 reasoning tokens），CoT 提示词的作用被内化；
  非思考型模型（如 moonshot-v1-8k、gpt-4o-mini）则完全靠提示词引导。
  评估一个提示词技巧时，要清楚自己在跟哪类模型打交道。
- **自我检查（self-check）**：让模型把答案代回原题验算。它不是万能的
  （模型可能用同样的错误思路"验证"自己），但能抓回一部分粗心错误，
  成本只是多一句话。

## 常见错误

1. **只要答案不要过程**：错了无从排查，对了也无法信任——工程上不可审计的输出
   等于没有输出。
2. **以为思维链万能**：题目有歧义或超出能力时，写过程照样会错。
   所以还要有自我检查、还要用评估集度量（见[第 5 章](../05_iteration/)）。
3. **在思考型模型上测不出差异就否定方法**：先想清楚模型把推理花在了哪里，
   换非思考型模型再下结论。

## 练习建议

1. 按上面的命令把 `MODEL_NAME` 换成 `moonshot-v1-8k` 重跑本章，
   记录三种提示词各自的得分，与本章 README 的表格对照。
2. 自己出一道带单位换算陷阱的题加入 `PROBLEMS`（注意先人工算好标准答案），
   看三种提示词的表现。
3. 删掉提示词里的"特别注意单位换算和隐藏条件"，只保留"先列推理过程"，
   在非思考型模型上对比得分变化（体会"点出易错点"也是提示词的一部分）。
