# 02 条件边与循环：图的灵魂

链（LCEL）是 DAG，表达不了"根据中间结果决定去向"；图的**条件边**补齐了这一点，
也让**循环**成为可能——而循环正是 Agent 的心跳。

## 本章要点

- `add_conditional_edges("节点", 路由函数)`：节点执行完后调用路由函数，
  函数返回下一个节点名（或 `END`）——条件分支的全部机制就这么多。
- **循环 = 路由函数返回上游节点**：本章的 `polish → route → polish → ...` 环，
  与 Agent 的 `LLM → 工具 → LLM → ...` 环是同构的。
- **永远给循环加上限**（本章的 `MAX_ITERATIONS`）：LLM 驱动的循环可能不满足退出条件，
  没有上限会烧光 token。

## 运行

```bash
uv run tutorials/langgraph/02_conditional/main.py
```

预期输出：语气词被一轮轮去掉，直到文案"达标"后退出循环。

## 核心概念

- **路由函数是普通的纯函数**：输入 State，输出节点名。复杂的业务分流（意图识别结果、
  检索分数阈值）都只是在这个函数里写 if/else。
- 下一章会看到：`create_react_agent` 内部正是"LLM 节点 + 工具节点 + 一条判断
  '模型是否还想调工具'的条件边"——你已经能徒手写出它了。
