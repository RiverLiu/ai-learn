# 云雀笔记产品介绍

## 产品定位

云雀笔记是一款面向个人知识管理的轻量笔记应用，支持 Windows、macOS、iOS 和 Android 四端同步。
产品理念是"记录零负担"：打开即写，不做复杂的笔记本层级管理。

## 核心功能

- **极速同步**：基于自研的差量同步引擎，平均同步延迟低于 300 毫秒，断网时自动进入离线模式。
- **Markdown 原生支持**：所有笔记以 Markdown 格式存储，支持代码块高亮、数学公式和 Mermaid 图表。
- **AI 摘要**：长按任意笔记可生成一句话摘要，每周自动生成"本周回顾"汇总。
- **双向链接**：使用 `[[笔记名]]` 语法建立笔记间的链接，自动生成关系图谱。

## 离线模式

离线模式下可以正常新建、编辑和搜索笔记，所有修改保存在本地数据库，
网络恢复后自动合并。若同一笔记在多台设备离线修改，合并时保留两个版本并标记冲突，
由用户手动选择保留哪一版。

## 数据存储

笔记数据在传输和静态存储时均使用 AES-256 加密。免费版数据保留最近 30 天的历史版本，
专业版保留全部历史版本。用户可以在设置中一键导出全部笔记，导出格式为 Markdown 压缩包。
