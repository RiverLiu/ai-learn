# 01 文本向量与语义相似度

RAG 的地基是 **Embedding**：模型把任意文本映射成一个高维向量（如 1536 维），
语义相近的文本，向量在空间中的距离也相近。

## 本章要点

- `client.embeddings.create(...)`：一次调用把一批文本转成向量，返回的向量可以直接做数学运算。
- **余弦相似度**：比较两个向量方向的夹角，取值 [-1, 1]，越接近 1 语义越相近。检索时用它给候选文本打分排序。
- 与关键词匹配的区别：查询"专业版多少钱"能命中"专业版每月 18 元"（有共同词），
  也能命中"云雀笔记专业版的定价是多少？"（**零共同词，纯语义相近**）——这正是 RAG 检索强于传统搜索的地方。

## 运行

需要 `OPENAI_API_KEY`（见[教程首页](../README.md#环境准备)）：

```bash
uv run tutorials/rag/01_embeddings/main.py
```

预期输出（分数因模型而异，但排序应稳定：两条价格相关在前，React 条目垫底）：

```
查询：专业版多少钱

  0.6..  云雀笔记专业版的定价是多少？
  0.5..  专业版每月 18 元，按年付费有优惠
  0.3..  团队版支持 SSO 单点登录
  0.2..  离线模式下修改会自动合并
  0.0..  React 是一个用于构建用户界面的 JavaScript 库
```

## 核心概念

- **语义即几何**：文本 → 向量后，"找相关内容"变成"找最近的向量"，这是所有向量检索的本质。
- **归一化后点积 = 余弦相似度**：`cosine_similarity()` 里先归一化再做矩阵乘法，是一次对成百上千候选打分的标准写法。
