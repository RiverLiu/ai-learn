# FastAPI Review

Workflow:

1. Start with routes, dependencies, auth, database access, and tests.
2. Prioritize concrete bugs, security risks, behavioral regressions, and missing validation.
3. Reference exact files and lines when reporting findings.
4. Keep style suggestions secondary unless they affect correctness or maintainability.
5. Mention tests that were not run.
